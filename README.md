## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/HarshaSai1234/Java_Projects.git
```

2. Open the project in your preferred IDE:
   - IntelliJ IDEA
   - Eclipse
   - VS Code

3. Compile and run:

```bash
javac FileName.java
java FileName
```
